## Platform

web

## Stack

delegated: static HTML, CSS, and JavaScript, preserved from the existing project

## Users

Visitors who want to quickly understand Zhang Zihao's public projects, technical interests, and recent activity.

## Product Purpose

This is a living project archive that turns public GitHub repositories into a browsable personal portfolio. Success means a visitor can find a project, understand its purpose, open its README or live demo, and verify its current GitHub activity within seconds.

## Positioning

The archive is automatically synchronized with GitHub instead of relying on a manually maintained project list. Repository activity, README content, and public Star counts are live evidence.

## Operating Context

The site is used in a browser on desktop and mobile. Visitors browse projects, filter by language, search project content, open a detail view, read a short README extract, and follow links to GitHub or a live demo.

## Capabilities and Constraints

- Preserve GitHub profile and repository synchronization.
- Preserve project search, language filters, project details, README loading, and live public Star counts.
- The public GitHub API can read Star counts without authentication; starring a repository must happen on GitHub in the visitor's own session.
- The project remains dependency-free and deployable as static files.

## Brand Commitments

The existing name is Zhang Zihao. The voice is direct, curious, and maker-focused. The GitHub profile and avatar are confirmed project assets.

## Evidence on Hand

GitHub profile `crazyzhang277`, public repositories, repository descriptions, topics, README files, public Star counts, and optional live demo URLs. No fabricated testimonials, metrics, or client claims should be introduced.

## Product Principles

- Show the work before explaining the interface.
- Treat live repository data as the source of truth.
- Make project discovery fast and readable.
- Let technical detail become visible on demand.

## Accessibility & Inclusion

Use semantic HTML, keyboard-accessible controls, visible focus states, readable contrast, responsive layouts, and reduced-motion behavior.
